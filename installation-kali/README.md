# Installation Kali

Kumpulan modul instalasi untuk Kali. Setiap modul memiliki skrip `basic.sh`, `pro.sh`, dan dokumentasi sendiri.

## Modul
- `audio`
- `browser`
- `cloud`
- `database`
- `editor`
- `image`
- `messaging`
- `office`
- `pentest`
- `remote`
- `security`
- `servers`
- `storage`
- `streaming`
- `tools`
- `utilities`
- `virtualization`

## Cara pakai

```bash
cd installation-kali
chmod +x basic.sh
./basic.sh
```

> Catatan: skrip root ini adalah entrypoint dan bisa dikembangkan sesuai kebutuhan orkestrasi Anda.
